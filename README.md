# Sakan | Real Estate & Accommodation Platform 🏠

**Sakan** is a robust, production-ready backend system designed to bridge the gap between property owners and tenants. This project was developed as a **Graduation Project** for the Faculty of Computer Science at Minya University , where it secured **5th Place** for its technical implementation and practical problem-solving approach.

## 🏆 Achievement

* 
**5th Place** in the Graduation Projects Competition for Minya University.


* Recognized for efficient database architecture and real-world applicability.



## 🚀 Features

* 
**Role-Based Access Control (RBAC):** Distinct permissions for Admins, Property Owners, and Regular Users.


* 
**Advanced Search & Filtering:** Dynamic query implementation for location, price ranges, and amenities.


* 
**Property Management:** Complete CRUD operations for property listings with image metadata management.


* 
**Security:** Secured endpoints using **Spring Security** and JWT-based authentication.


* 
**Scalable Architecture:** Built following **SOLID principles** and **Clean Architecture** patterns.



## 🛠️ Tech Stack

* 
**Language:** Java 17+ 


* 
**Framework:** Spring Boot (MVC, Security, Data JPA) 


* 
**Database:** PostgreSQL / MySQL (Relational Schema Design) 


* 
**ORM:** Hibernate 


* 
**Tools:** Maven, Git, Docker 



## 🏗️ Getting Started

### Prerequisites

* Java JDK 17 or higher
* Maven
* PostgreSQL (or Docker for containerization) 



### Installation

1. Clone the repository:
```bash
git clone https://github.com/mohamedabdeldayem7/sakan.git

```


2. Configure your database settings in `src/main/resources/application.properties`.
3. Build the project:
```bash
mvn clean install

```


4. Run the application:
```bash
mvn spring-boot:run

```
